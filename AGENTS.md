# User rules

- Treat the entire `C:\` drive as off-limits. Do not explicitly read, search, inspect, execute, create, modify, copy, move, or delete files or directories on that drive.
- Keep task artifacts, temporary files, logs, and backups on `D:\`.
- Do not use a skill or workflow that requires accessing files on `C:\`.
- If work requires access to `C:\`, explain the limitation and continue any independent work that can be completed on `D:\`. Do not access `C:\` unless the user explicitly changes this rule.
