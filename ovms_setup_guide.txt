How GPU Communication:
 WorksData Parallelism: Both GPUs hold a full copy of the model. They split the data to process it faster.
 Model Parallelism:     The model is too big for one card. The system splits the layers across both GPUs.
 Pipeline Parallelism:  GPU one does the first steps. It hands the results to GPU two for the next steps.

Tools and Frameworks:
  PyTorch DDP:  Use PyTorch DistributedDataParallel to share work across both cards easily.
  DeepSpeed:    Use Microsoft DeepSpeed to save memory and train giant models.
  Hugging Face: Use the Hugging Face Accelerate library to set up multi-GPU training with simple code.
